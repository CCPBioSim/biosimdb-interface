biosimdb-interface
==================

.. ccpbiosim-hero::
   :logo-light: _static/logos/biosimdb-logo-black.png
   :logo-dark: _static/logos/biosimdb-logo-white.png
   :logo-alt: BioSimDB logo
   :tagline: biosimdb-interface
   :button: biosimdb_intro | Get started
   :github: CCPBioSim/biosimdb-interface

   A web interface for extracting simulation metadata and uploading it to BioSimDB

A web interface for extracting simulation metadata and uploading it to the
`BioSimDB <https://data-collections.psdi.ac.uk/communities/biosimdb>`_ community data collection,
hosted by PSDI.
